# Corrected Section 5.3 AR(1) power study

Run from the `svpChange` package root:

```r
source("simulations/power_ar1/calibrate_ar1.R")
calibration <- run_ar1_calibration(workers = 8L)
source("simulations/power_ar1/run_power.R")
run_and_save_ar1(workers = 8L, calibration = calibration)
source("simulations/power_ar1/export_paper_figures.R")
export_ar1_paper_figures(calibration = calibration)
```

The study follows Section 5.3 of `SVP_NEW.pdf`: `n=600`, `rho=0.8`, unit
stationary marginal variance, four signal patterns, jump sizes from 1 to 5 in
steps of 0.2, and 100 replications. AR(1) data are generated by
`ts_generator(type = "gaussAR1")` with innovation standard deviation
`sqrt(1-rho^2)`.

The four algorithms are `PELT AR1 approximate`, `PELT inflated`, `DeCAFS AR1`,
and `SVP AR1Focus + AR1 cost / right`. The approximate PELT method applies PELT
to `y[-1] - rho*y[-n]`, maps transformed endpoints back to the original series,
and uses a calibrated penalty `c_P*log(n)`. The inflated PELT baseline remains
fixed at `3*log(n)*(1+rho)/(1-rho)`.

## DeCAFS requires version 3.3.6 or later

`calibrate_ar1.R` refuses to run against an older DeCAFS. The calibration RDS
and CSV tables record the exact DeCAFS version used. Builds before 3.3.6
initialised the dynamic programme with precision `1/(sdNu^2 (1-phi^2))` on
`(y[1]-mu[1])^2`, where equation (4) of the DeCAFS paper, and the package's own
README, give the stationary AR(1) precision `(1-phi^2)/sdNu^2`. At `rho = 0.8`
that over-weights the first observation by a factor `(1-rho^2)^-2 = 7.7`, so
`mu[1]` is pulled onto `y[1]` and an almost free spurious change appears in the
first few observations: under the null at `beta = 2*log(n)`, 37% of series got a
false change and half of those fell in the first 20 points. Suppressing them
through the penalty is what previously pushed the calibrated DeCAFS constant to
`7.75*log(n)` and cost it power everywhere. With the fix it calibrates to
`2.75*log(n)`, next to the package default of `2*log(n)`, and DeCAFS leads the
study.

## The SVP within-segment cost

SVP first minimises the number of valid segments and then ranks the partitions
that attain it by their within-segment cost, so the cost decides only where the
boundaries sit. This study now passes `cost = "ar1"` to `SVP()`, which scores a
segment `(s, t]` by the sum of squared deviations of its interior innovations
`z[u] = y[u] - rho*y[u-1]`, `u = s+2, ..., t`. The innovation `z[s+1]` that
straddles the boundary is skipped: its mean carries the jump, so charging a
segment for it pulls the boundary away from the change. Every partition into
`K` segments skips exactly `K-1` innovations, so costs stay comparable within
the `K` that SVP compares.

Previously the study used the Gaussian squared-error cost on the raw
observations, which is misspecified under serial dependence.
`svp_cost_comparison.csv` records the comparison that decided the switch: the full
power grid, both costs at the same calibrated threshold `c = 1.95`. The two
agree on the number of segments for every one of the 8,400 series, as they must,
and the AR(1) cost is better everywhere else:

| pattern | F1 (gaussian -> ar1) | MSE | localisation error given correct K |
|---|---|---|---|
| `up`     | 0.754 -> 0.780 | 0.446 -> 0.423 | 1.61 -> 0.31 |
| `updown` | 0.667 -> 0.682 | 0.369 -> 0.348 | 1.79 -> 0.38 |
| `rand1`  | 0.735 -> 0.747 | 0.298 -> 0.288 | 7.36 -> 2.21 |
| `none`   | 0.997 -> 0.997 | unchanged | not applicable |

Both costs also share one null calibration curve, because the cost never changes
how many changes are detected; only the calibrated SVP row appears in the study.
The study's SVP row also moved from `c = 1.85` to `c = 1.95` because the null
target itself moved once DeCAFS was fixed, so the study-to-study SVP difference
mixes the two effects; the table above isolates the cost.

## Calibration

DeCAFS is calibrated to corrected null F1 at least 0.99. The approximate PELT
penalty and SVP AR1Focus threshold are selected to match the selected DeCAFS
null F1; for the recorded run, this empirical target is 0.995 (the nominal
target is 0.99). Calibration uses 1,000 null series and validation uses 1,000
independent null series, with deterministic seeds and Wilson intervals.
The selected values are in `selected_parameters.csv`.

All metrics use `simulations/power_common.R`: endpoint `n` is excluded,
matches are one-to-one within a five-observation tolerance, and the output
contains precision, recall, F1, correct-number probability, MSE, segment count,
and localization error.

The full study has `4*21*100*4 = 33,600` method rows. Previous outputs are
preserved in `simulations/other_simus/power_ar1_legacy_20260915/`.
